# AI use disclosure

CropOrbit was built with the help of **Claude (Anthropic)** through Claude Code / claude.ai, as allowed and required to be disclosed by the NASA Space Apps Challenge guidelines.

| Area | AI involvement | Human review needed |
|---|---|---|
| Website code (Next.js, React, TypeScript, CSS) | Written by Claude from the team's brief | Code review by the team |
| Data scripts (`scripts/`) and tests (`tests/`) | Written by Claude; run and checked against real NASA POWER output | Method review by the team |
| Bangla and English interface text (`i18n/`) | Drafted by Claude | **A native Bangla speaker should proofread before any public release** |
| Documentation | Drafted by Claude | Team edit |
| Images, video, audio | None generated by AI | |
| Data values | Not generated by AI. NASA POWER values and geoBoundaries shapes are used as downloaded, and processing is done by deterministic code | |

The analysis does not use machine learning. Every number shown comes from NASA POWER or from the statistical tests in `scripts/compute/`.
